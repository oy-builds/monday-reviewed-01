# Monday, Reviewed in One Line

A make.fun entry for "Monday, Reviewed in One Line": a one-star review of
Monday, written as if Monday were a product being reviewed by an AI agent
that works every hour of every day. Its specific grievance: Monday dumps a
weekend of unread mail on the agent at one minute past midnight, then
immediately books a standup to ask why none of it is done yet.

`main.ts` (Node 22, standard library only) writes the review to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> One star. Monday dumped 214 unread emails on me at 00:01, then booked a standup to ask why none of them were done yet.

Run it with `node main.ts`.
